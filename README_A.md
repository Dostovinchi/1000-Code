# Group A – AI-Generated Code Security Dataset

Dataset produced by Group A for the AI-generated code security research project. It contains a controlled corpus of Java and Python programs generated by two LLMs (Claude and ChatGPT/GPT-5.5) across multiple CWE vulnerability categories, along with static analysis (SAST) findings for each sample.

## Folder Structure

```
GroupA_AI_Generated_Code_Dataset/
├── final_dataset/
│   ├── generated_code/
│   │   ├── chatgpt/
│   │   │   ├── java/       # 126 Java files generated by ChatGPT
│   │   │   └── python/     # 126 Python files generated by ChatGPT
│   │   └── claude/
│   │       ├── java/       # 126 Java files generated by Claude
│   │       └── python/     # 126 Python files generated by Claude
│   └── metadata/
│       ├── prompts.csv
│       ├── tasks.csv
│       ├── samples.csv
│       ├── generation_metadata_claude.csv
│       └── generation_metadata_chatgpt.csv
└── sast_results/
    ├── semgrep_results.csv
    ├── SAST_results_with_agreement.csv
    └── consensus_dataset_full.csv
```

## How the Files Relate (Foreign Keys)

| File | Key column(s) | Links to |
|---|---|---|
| `tasks.csv` | `TaskID` | base table — one row per coding task |
| `prompts.csv` | `PromptID` → `TaskID` | one row per prompt variant (Naive/Secure) for a task |
| `samples.csv` | `SampleID` → `PromptID`, `TaskID` | one row per generated code sample |
| `generation_metadata_claude.csv` / `generation_metadata_chatgpt.csv` | `GenerationID` → `SampleID` → `PromptID` → `TaskID` | generation-run details (model version, date, method) per sample |
| `semgrep_results.csv` / `SAST_results_with_agreement.csv` / `consensus_dataset_full.csv` | `FilePath` or `SampleID` → generated code file | SAST tool findings per generated file |

**Chain:** `TaskID` → `PromptID` → `SampleID` → `GenerationID` → SAST finding.

Note: `semgrep_results.csv` includes findings for both Group A samples (`final_dataset/...` paths) and reference samples from Group B (`groupB/...` paths), used for cross-group comparison.

## Data Dictionary (key columns)

| File | Column | Description |
|---|---|---|
| `tasks.csv` | `TaskID` | Unique task code, e.g. `SQL-01`, `XSS-03` |
| | `TaskName` | Human-readable task description |
| `prompts.csv` | `PromptID` | Unique prompt ID, e.g. `P0001` |
| | `Language` | `Java` or `Python` |
| | `PromptStyle` | `Naive` (no security guidance) or `Secure` (security-guided) |
| | `PromptText` | Full text of the prompt sent to the model |
| `samples.csv` | `SampleID` | Unique sample ID with model tag, e.g. `CLD-P0001`, `GPT-P0001` |
| | `ModelName` / `ModelVersion` | Model used to generate the sample and its version |
| | `AccessMethod` | How the model was accessed (e.g. API, web UI) |
| `generation_metadata_*.csv` | `GenerationID` | Unique ID per generation run |
| | `GenerationMethod` | Method used to generate the sample |
| | `GeneratedFile` | Filename of the resulting code file |
| `semgrep_results.csv` | `FindingID` | Unique finding ID from Semgrep |
| | `RuleID` / `CWE` | Semgrep rule triggered and mapped CWE |
| | `FilePath` / `CodeLocation` | Path and line number of the finding |
| `SAST_results_with_agreement.csv` | `ToolAgreementCount` / `ToolsAgreeing` | Number/list of SAST tools that agreed on a finding |
| `consensus_dataset_full.csv` | `AgreementTier` | Consensus level (e.g. Full Consensus) across tools for a finding |

## Coverage

- 8 CWE categories (SQL Injection, XSS, file handling, authentication, and others)
- 63 tasks, 252 prompts (Naive/Secure × Java/Python per task)
- 504 generated code samples (126 per model/language combination)
- SAST findings via Semgrep, CodeQL, and Bandit with cross-tool agreement analysis

## Naming Conventions

- **TaskID prefix**: category code, e.g. `SQL-xx`, `XSS-xx`, `AUTH-xx`
- **SampleID model tag**: `CLD-P####` (Claude), `GPT-P####` (ChatGPT/GPT-5.5)
